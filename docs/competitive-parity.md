## Immersive Translate consideration checklist

Verify webpage bilingual modes, hover/selection translation, subtitle/video behavior, PDF/e-book/document support, site customization, input translation, keyboard shortcuts, provider selection, glossary/custom prompts, mobile/browser coverage, and subscription boundaries. Consider parity only where it supports the Lingo constitution; do not copy interaction details, assets, wording, or implementation.

## Research protocol

For each product capture official source URL, date, supported platform/plan, observed behavior, permissions/data recipients, accessibility/BiDi notes, limitations, and a synthetic reproduction. Separate documented claims from observed evidence. Competitive evidence can suggest a requirement but cannot override product/privacy decisions.
