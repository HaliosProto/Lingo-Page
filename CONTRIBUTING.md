# Contributing

Read `AGENTS.md`, `PRODUCT_CONSTITUTION.md`, `ROADMAP.md`, `TASKS.md`, and the approved milestone specification before changing the repository. Work on one approved milestone or bounded task at a time.

Use the contract-first flow in `docs/spec-driven-workflow.md`: discover, specify, clarify, design, plan, accept, implement, verify, record, and stop for review. Use Beads as the execution graph (`bd prime`, `bd ready`, `bd show`, `bd update`, `bd close`); do not create competing task lists or memory files.

Preserve package boundaries, least permissions, backend-only credentials, plain-text DOM insertion, runtime validation, and privacy-safe diagnostics. Never use real page content or credentials in fixtures, logs, screenshots, issues, or commits.

Run the applicable commands from `AGENTS.md` and record exact evidence. Browser, accessibility, security, persistence, or performance claims require the corresponding runtime evidence, not only types or unit tests. Do not push, deploy, publish, provision, or make paid/external calls without exact authorization.
